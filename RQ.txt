Detection accuracy: Does fine-tuning improve the model's ability to correctly classify/detect threats (true positive rate) without inflating false positives?
Experiment: Curate a labeled test set of threat scenarios (log snippets, code diffs, network events, CVE descriptions — whatever your input modality is) with ground-truth labels. Evaluate base model vs. fine-tuned model on:
Precision, recall, F1, per threat category
Confusion matrix across categories (e.g., which threat types get confused with which)
ROC/PR curves if you can get confidence scores
Hold out a test set the fine-tuning data never touched, and ideally use k-fold cross-validation on the training data itself to check fine-tuning stability.
